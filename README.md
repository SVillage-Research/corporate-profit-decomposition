# 企業の最高益はどこから来たのか：再現コード

SVillage の記事「実質の売上はほとんど増えていないのに、企業はなぜ最高益なのか――法人企業統計で、経常利益124.8兆円の中身を調べる」の数値と図を再現するコードです。

記事：<https://s-v.jp.net/?p=3021>

**このリポジトリは、コードだけを公開しています。生データは含みません。**データは、下の公式の入手先から取得します（取得用のスクリプトと、手順を用意しています）。

## できること

2012年度から2025年度の、全産業（金融業・保険業を除く）の法人企業統計を中心に、次を計算し、図11枚を作ります。

- 経常利益の増加分の、営業利益・営業外収益・営業外費用への分解
- 営業利益の増加分の、売上の増加と利益率の上昇への分解
- 売上高を物価指数で割った目安、売上原価率・販管費率・人件費率の変化
- 国際収支の直接投資収益との比較、為替を固定した場合の円換算額の試算
- 付加価値の分配、労働分配率（規模別を含む）
- 内閣府の国民経済計算（SNA）との比較

## 法人企業統計（e-Stat）の取得

次の2つの方法のどちらかで取得します。どちらも、取得するデータは同じです（下の「どのデータが必要か」）。

### 方法A：e-Stat API（推奨）

[e-Stat の API 機能](https://www.e-stat.go.jp/api/)で利用登録（無料）をして、appId を取得します。環境変数 `ESTAT_APP_ID` に入れるか、`python fetch_estat_api.py` の実行時に入力します（画面には表示されません）。`data/estat/` に、下の3つのCSVが作られます。**appId は他人に渡さず、リポジトリにも入れないでください**（コードは appId をファイルに保存しません）。

取得後、記事執筆時の値（2025年度・全産業・全規模の経常利益など）との照合結果が表示されます。

### 方法B：画面からダウンロード

下の「どのデータが必要か」の表と「手順」のとおりに、画面からCSVをダウンロードします。

### どのデータが必要か

**同じ表を、業種と規模の選び方を変えて、3回ダウンロードします。**

- **表：**法人企業統計調査 時系列データ 表1「金融業、保険業以外の業種（原数値）」。年度（4月〜翌年3月）の表です。
- **期間：**1980年度から2025年度まで。画面の既定（1960年度から最新年度まで）のまま、全年度をダウンロードして構いません（コードが1980年度以降を使います。純粋持株会社は2009年度以降が使われます）。
- **項目：**全項目のまま（画面右側の「表示項目選択」は変えない）。コードが使うのは、次の27項目です。母集団、資産合計、売上高、売上原価、販売費及び一般管理費、営業利益、営業外収益、営業外費用、経常利益、特別利益、特別損失、当期純利益、配当金計、社内留保、減価償却費計、役員給与、役員賞与、従業員給与、従業員賞与、福利厚生費、支払利息等、動産・不動産賃借料、租税公課、期中平均役員数、期中平均従業員数、付加価値、営業純益。

3つのファイルを、`data/estat/` に置きます。CSVでもExcel（.xlsx）でも構いません。ファイル名は自由です（ファイルの中の「業種」「規模」の値から、どの表かを自動で判定します）。

| 画面での選択（「業種」「規模」） | 何に使うか |
|---|---|
| 業種＝全産業（除く金融保険業）、規模＝全規模 | 記事の中心。経常利益の分解、売上、費用率、労働分配率、付加価値 |
| 業種＝純粋持株会社、規模＝全規模 | 純粋持株会社を除いた確認 |
| 業種＝全産業（除く金融保険業）、規模＝10億円以上 | 労働分配率の規模別（10億円以上と、差し引きで求める10億円未満） |

### 手順

1. [e-Stat 法人企業統計調査 時系列データ 表1](https://www.e-stat.go.jp/dbview?sid=0003060791) を開く。
2. 画面上部の「業種」「規模」を、上の表のとおりに選んで「再表示」を押す。
3. 項目と年度は変えない（全項目・全年度）。
4. 画面の「ダウンロード」から、CSVまたはExcel形式を選んで保存する。
5. `data/estat/` に置く（Colab では、ノートブックの指示に従ってアップロード）。

画面の表記や手順は、e-Stat の更新で変わることがあります。うまくいかない場合は、`parse_estat.py` の先頭の説明（読み込めるCSVの形）を確認してください。ダウンロードした表は、次の値で確かめられます（全産業・全規模、2025年度、百万円）：経常利益 124,831,342、売上高 1,720,255,968、付加価値 373,670,064。

## 数値の照合について

`check_article_numbers.py` は、記事の主な数値を計算結果と突き合わせます。**統計は改定されます。**とくに、国際収支の再投資収益は、毎年11月に改訂されます。記事執筆時（2026年10月10日）以降にデータを取得すると、記事の数値と一致しないことがあります。

`fetch_data.py` は、取得したデータの指紋を、記事執筆時の値と比べて表示します。

## 注意

- 数値はすべて名目で、法人単体の決算の集計です。実質売上は、国内企業物価指数と企業向けサービス価格指数で割った目安です。
- 円安の寄与の試算は、直接投資収益の全額がドル建てと仮定したシナリオ計算です。
